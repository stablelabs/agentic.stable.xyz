# Project source

The source is this repository, including `web/`, `server/`, `shared/`, `examples/`, and `tests/`.

The source repository is [stablelabs/agentic.stable.xyz](https://github.com/stablelabs/agentic.stable.xyz). It is currently private, so access requires repository permission. Public availability must be approved separately before advertising an unrestricted reproduction path.

Set `REPOSITORY_URL=https://github.com/stablelabs/agentic.stable.xyz` to route the site's GitHub link to this repository.

See [quickstart](/docs/quickstart/) for commands that run from the current checkout.
